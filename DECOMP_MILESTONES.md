# Decompilation Milestones

## Scope and acceptance criteria for this work session

No pre-existing milestone specification was present in the repository when this
work began. For this session, "Milestone 2" and "Milestone 3" are therefore
defined by the user request and by falsifiable repository state:

The user explicitly approved these session definitions as the authoritative
acceptance criteria after repo docs, git history, GitHub milestones, GitHub
issues, GitHub discussions, and web search did not reveal a pre-existing
Milestone 2 / Milestone 3 specification.

- Milestone 2 is complete when the current decompilation state is verified,
  remaining menu and non-menu frontiers are counted, the next non-menu frontier
  is selected by a reproducible criterion, and that evidence is recorded here.
- Milestone 2 does not require removing the two remaining `src/MENU`
  `INCLUDE_ASM` sites, because no repository milestone document defines menu
  completion as the acceptance criterion for this session.
- Milestone 3 is entered when work begins on the selected non-menu frontier and
  reaches a build-safe, falsifiable checkpoint: guarded draft code compiles under
  `OBJDIFF`/`PERMUTER`, normal matching builds remain green through the asm
  fallback, and the remaining nonmatching status is documented.
- Milestone 3 is not complete in the sense of removing every `SCREFF2.PRG`
  `INCLUDE_ASM`; this checkpoint satisfies the user instruction to move on to
  Milestone 3 after Milestone 2, not to finish all of Milestone 3.
